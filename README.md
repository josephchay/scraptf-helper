# TF2 Flip Desk

A Windows desktop app that runs in the background and tells you which TF2 items are worth flipping. It compares the scrap.tf prices you give it with live backpack.tf buy orders. It groups the profitable items, keeps a running log of them, and gives you one-click links to backpack.tf, marketplace.tf, Steam Community Market, STN and PriceDB. For every item it tracks, it also shows the most you can pay on scrap.tf and still make your profit, so you know what to look for before you start browsing.

It replaces two userscripts:
- **tf2-scraptf-profit-helper** (VeBeshka): profit badges on scrap.tf.
- **scrap.tf-item-information** (NetroScript): the middle-click link menu.

Neither userscript is used, and no extension or preload runs in any website. The one exception is the opt-in scrap.tf window, which runs one read-only snapshot script on the scrap.tf pages shown in it.

## Why this design keeps your accounts safe

No tool can promise it is "undetectable". scrap.tf, backpack.tf and marketplace.tf share one owner (ScrapTF, LLC) and can ban at their own discretion. The safe approach is to do nothing a site prohibits, rather than hide what you do. The app is built that way, and tests enforce it. The one exception is the opt-in **scrap.tf window** (new in 0.7, off by default): there you browse scrap.tf yourself inside Flip Desk while it reads what is on screen, and that is outside scrap.tf's rules as written, at your own risk (see below the table).

| The app never… | Instead it… |
|---|---|
| fetches scrap.tf on its own: no page loads of its own, no `/ajax`, no socket, no polling, no auto-refresh. The scrap.tf ToS forbids "automation, scripts, user-scripts, auto-refreshers, external tools" for advantage. | gets scrap.tf prices only from **you**: typed in, from category rules, from pages you saved yourself (opt-in), from text you copied and asked it to check (Live check), or, if you turn it on, from the scrap.tf window, which shows scrap.tf only as you browse it. |
| clicks, types, scrolls or changes anything on scrap.tf, buys or queues anything there, reads or reuses your scrap.tf cookies or sign-in, changes its user agent, or gets past a Cloudflare check for you. | in the scrap.tf window, loads a page only when you click (in the page or on its toolbar), takes a read-only snapshot of each scrap.tf page that loads there (from your click, or a reload or page switch the page makes itself), as saving it would, and leaves the sign-in and any check to you. The read sends nothing over the network. |
| reads your browser: its pages, its history or its windows. | reads only plain text you copy, when you press the check hotkey or while you have the clipboard check on, on this computer. That text is never stored, logged or sent anywhere. |
| scrapes HTML from backpack.tf or marketplace.tf. The old profit helper scraped up to 6 classifieds pages per item; backpack.tf's API terms forbid page scraping. | uses backpack.tf's **public websocket** and its **documented JSON APIs** with your own key and token, kept well under the published limits. |
| buys, sells, trades, lists, bumps or accepts anything, anywhere. | leaves every trade to you, in your browser and Steam client. |
| spoofs a browser, rotates proxies, solves CAPTCHAs or randomises timing. | sends an honest User-Agent (`TF2FlipDesk/<version> (+your contact URL)`) and stops when a site serves a challenge page. The scrap.tf window keeps Electron's own user agent, which names Flip Desk and Electron. |
| asks for, reads or stores Steam passwords, cookies or authenticator secrets. | encrypts your API key and token with Windows DPAPI and redacts them from every log. In the scrap.tf window you sign in on Steam's own page; the session stays in that window's own browser storage, in memory unless you choose to stay signed in. |

**Remaining risk.** scrap.tf's "external tools" wording is broad, and could cover even a tool you only type prices into. The **Import** page includes a ready-to-send email to `admin@scrap.tf` asking whether this is OK. Sending it is optional, and you send it from your own email.

**The scrap.tf window is a bigger risk, and you take it on yourself.** Its reads are an external tool used on scrap.tf's pages, scrap.tf staff have ruled scripts out on banking pages, and the window's user agent lets scrap.tf see what you browse with. scrap.tf may ban your account for it, and possibly your backpack.tf account too (same owner). It stays off until you turn on saved-page import and tick two acknowledgements, and everything else in Flip Desk works without it.

## Install and run

**Installer:** run `release\TF2 Flip Desk Setup 0.7.3.exe` (built by `npm run dist`). It is unsigned, so Windows SmartScreen will warn you on first launch.

**From source** (Node 24+):

```bash
npm install
```

```bash
npm start
```

Closing the window keeps the app running in the tray. Use the tray menu to open the dashboard, open quick entry, open the scrap.tf window (once you turned it on), pause the live feed or all network access, turn the clipboard check on or off, or quit.

## First run

1. **Settings → Contact URL.** Add something that reaches you, such as your Steam profile URL. It goes into the User-Agent so API operators can contact you instead of blocking you.
2. **Settings → backpack.tf.** Add your **access token** and **API key**. Both are on <https://next.backpack.tf/account/api-access>, and they are two different values:
   - **Access token:** click *Reveal* under *Access Token*.
   - **API key:** under *API Key*, register a key first (any site URL such as `http://localhost`, plus a short comment), then copy it. A 403 "This API key is not valid" almost always means the access token or a Steam Web API key was pasted here.
   - The live buy-order feed works without them.
   - The token enables on-demand and watched-item refreshes.
   - The key adds backpack.tf community prices and backpack.tf's key price.
   - PriceDB already provides a key price without a key.
3. Add your first scrap.tf price (next section). The quickest is to save scrap.tf/items once (Daily workflow, step 1): it prices every item scrap.tf trades. Quick entry and the price sheet stay there for single prices.

## Daily workflow

1. **Sync every scrap.tf price in one save.** scrap.tf publishes one price list of every item it trades, at <https://scrap.tf/items>. Save it once and the whole list reaches every part of the app.
   - **Once:** turn on **Import** (after reading the ToS note) and choose a **Watch folder**. The *scrap.tf price list* card at the top of the Live market and on the Import page walks you through both.
   - **Open scrap.tf/items** (the card's button). The page opens in your own browser; the app only hands it the address.
   - Press `Ctrl+S`, choose **Webpage, Complete**, and save it into your watch folder. The card shows the folder's path with a Copy button. Not *Webpage, Single File* for this page: the list has an image for every item, and one `.mhtml` file of it goes over the import's limits (20 MB, 2,000 parts) and is refused. *Webpage, HTML only* still imports, but it keeps the page as it first loaded. The `_files` folder a complete save adds is ignored.
   - Flip Desk picks it up within seconds and updates prices, the Live market, Holdings and the key price. For every item the list has, it stores what scrap.tf charges (*Price to buy*), what it pays you (*Price we pay*) and its stock against its limit. Out-of-stock items count too, because scrap.tf still buys them.
   - The card then reads *All scrap.tf items: 2,341 from your saved price list, saved 3 min ago*: green up to 15 minutes, amber up to 2 hours, grey after that. If scrap.tf splits the list into several pages, save each one; they merge item by item, and the newest save wins.
   - **With the scrap.tf window on** (step 3), the card's **Open in Flip Desk window** opens scrap.tf/items there instead. The window reads it as it loads, so you need no watch folder for it; the card's *No watch folder* note then says the folder is optional.
   - **Flip Desk never loads scrap.tf on its own; your browser (or the Flip Desk window) does, when you choose.** The list is exactly as fresh as your last save, so save it again whenever you start a session.

   What one save changes:
   - **Live market:** the *scrap.tf pays* and *Stock* columns (stock n of its limit, with *Full* when scrap.tf will not buy more), an **All items** chip at the front of the saved-page strip, and an *On scrap.tf's list* filter under *Source*. Items in stock also become your scrap.tf price, exactly as any saved page does.
   - **Item panel:** a *scrap.tf price list* block (sells, pays, stock, when you saved it) with **Use as my price** and **Open scrap.tf/items** (the panel's own **Open on scrap.tf** opens the item's bank page).
   - **Quick entry:** a *scrap.tf list* line under the item, with a **Use** button that fills in the price.
   - **Holdings:** scrap.tf's bank becomes a second place to sell (step 14).
   - **Key price:** the list's Mann Co. Supply Crate Key row gives scrap.tf's own key prices. When they are newer than the ones you typed (or you typed none), what scrap.tf pays for a key caps the automatic key value. Settings → Key price shows them and says whether they are in use.
2. **Work through the banks.** The **scrap.tf banks** page (in the sidebar after Live market) has one card per scrap.tf page you can save: Hats, Weapons, Stranges, Killstreaks, Skins, Items, Unusuals and *All items* (your scrap.tf/items list from step 1). Its header says how many of the 8 you saved in the last hour, and *12 flips on your saves, newest 3 min ago* with **View all**, which opens the Live market on every flip priced from a page you saved, freshest price first (`#/market/flips`).
   - **Each card** says when you last saved that page (*Fresh* up to 15 minutes, *Aging* up to 2 hours, then *Stale* or *Never saved*), how many items it had and how many of them were in stock.
   - **Open in browser** opens the page in your own browser. Save it with `Ctrl+S` as *Webpage, Complete* (or *Webpage, Single File*, except for scrap.tf/items) into your watch folder, as in step 1, and the card updates within seconds. The arrow keys move between cards and `Enter` opens the focused one.
   - **Saved without its items?** scrap.tf adds a bank's cards after the page has loaded, and *Webpage, HTML only* keeps the page as it first loaded. A bank page saved with no card at all is not counted: the Import page and a notice on any dashboard page say *This page was saved without its items…* (**How to save** opens the Import page), and the card, the Live market's chip and the stock page keep your last save that had cards. Nothing is removed. Save it again as *Webpage, Complete*.
   - **Flips from this page** counts the profitable flips whose scrap.tf price came from your saved copy of that page, with their total profit and the best three. For a bank page with a stock snapshot (step 4) it is exactly that page's *Flips* chip. Click one to open the item panel, or right-click it for the row menu.
   - **What to look for** lists up to five items of that page's categories that backpack.tf buyers want and you have no scrap.tf price for yet, highest *Pay up to* first: look for them on that page. **See all** opens the Live market filtered to those categories and *Not checked*. Right after you saved a single bank page (within your *Price is stale after* time: Settings → Profit thresholds, 2 hours by default), the heading reads *Not in your save 12 min ago: watch for restocks*: those items were not on sale when you saved it.
   - The app knows which page a file came from by the address your browser writes into the saved file, so each save counts for its own card whatever it holds. The Import page shows which card each save counted for.
   - **Flip Desk never loads scrap.tf on its own.** Your browser does, when you choose (or the Flip Desk window, as you browse it), and the app reads only the files you saved and the pages you browse in that window.
3. **Browse scrap.tf inside Flip Desk** (opt-in, off by default, new in 0.7). Instead of saving each page with `Ctrl+S`, you can browse scrap.tf in a Flip Desk window and let the app read what is on screen.
   - **The risk first.** scrap.tf's Terms of Service forbid "automation, scripts, user-scripts, auto-refreshers, external tools" for an advantage, its staff have ruled scripts out on banking pages, and the window's user agent names Flip Desk and Electron, so scrap.tf can see what you browse with. scrap.tf may ban your account for it, and your backpack.tf account too (same owner). Every other step here works without the window.
   - **Turn it on** in Settings → *scrap.tf window (opt-in)*, which says what the window does and never does: with saved-page import on (and its acknowledgement, step 1), tick the window's own acknowledgement, then *Turn on the scrap.tf window*. Turning import off, or unticking either acknowledgement, turns the window off and closes it.
   - **Open it** from *scrap.tf window* in the sidebar, **Open in Flip Desk window** on a scrap.tf banks card, on a bank's stock page or on the *scrap.tf price list* card, *Open scrap.tf window* in the tray menu, or **Open the scrap.tf window** in Settings. It opens on scrap.tf's front page, or on the page you chose; opening the page already on screen only brings the window to the front. The window remembers its size and place, and opens on a screen that is there.
   - **Browse as you would in a browser.** Sign in through Steam on Steam's own page, solve any Cloudflare check yourself, and click around. The toolbar has **Back**, **Forward**, **Reload** and **Home** (`Alt+Left`, `Alt+Right`, `F5` or `Ctrl+R`, `Alt+Home`), one chip per bank, the address (without its query), **Read page now**, **Log out & clear** and an *External-tool risk* pill. The keys, and the mouse's back and forward buttons, also work while the page itself has the focus. A link to backpack.tf, marketplace.tf or another site the app links to opens in your default browser, one tab per click of yours (a page cannot open one on its own); any other page outside scrap.tf and Steam's sign-in is not opened.
   - **What it reads.** When a scrap.tf page Flip Desk imports (a bank page, the unusual pages, scrap.tf/items) finishes loading in the window, or moves to another page in place, Flip Desk takes a read-only snapshot of the page on screen, and one more 4 seconds later, because scrap.tf adds bank cards after the page has loaded. That follows your clicks and also what scrap.tf's own scripts do (a reload, a page switch); the app cannot tell the two apart. The two snapshots are one look at the page and are imported once, as the newer one, exactly as the same page saved as *Webpage, Complete* would be: prices, bank stock and what's new, history, new-flip notifications and the Live market all update. While that look is under way the toolbar says *Reading…*, then *Read 48 items from /buy/hats · stored 46 · 10 flips (2 new) · best Team Captain +0.44 ref · 3 s ago* (*stored* only when it differs from what was read). A page loaded again within 30 seconds is not read again (unless nothing could be imported from it then, a Cloudflare check say), an unchanged page is not imported twice within a minute (the toolbar then shows that page's last read with *Read page now to read it again*), and **Read page now** reads at once (at most every 2 seconds, and not while the page is still loading). Turn *Read scrap.tf pages as they load* off to read only when you press it. A read is a local snapshot and sends nothing. Steam's sign-in and Cloudflare's check frame are never read. A Cloudflare check, error or rate-limit page shown at a scrap.tf address is not read when it loads: the toolbar says which it is (*wait a minute before reloading* for a rate limit), and **Read page now** still reads it, importing nothing. A page that failed to load or crashed says so, ending *press Reload*. Pages Flip Desk does not import (scrap.tf's front page, raffles, settings, a profile) are never read, and **Read page now** is off there. A bank page read before its cards arrived says *no items on screen yet; wait for them, then Read page now*. scrap.tf/unusuals itself is only an index of the unusual pages and lists no items: the toolbar says *this is the Unusuals index, which lists no items: open one of its pages to read it*. While Flip Desk is still loading item data at start, a read imports nothing and says *item data is still loading; press Read page now in a moment*.
   - **A look that caught only part of a page** is kept as prices only, with no stock snapshot, so nothing reads as gone: a look cut short before its second snapshot (you clicked on to another page within 4 seconds), and one with fewer than half the cards of your save of the same page from the last 6 hours (the toolbar says *only 12 of ~48 items were on screen, so no stock save*). Read the page again once every card shows.
   - **Show flips.** After a read, the status line counts the flips on the page and names the best one; click the name to open it in the dashboard, or **Show flips** to open the bank's stock page there on its *Flips* chip, where the new ones carry a *New* badge. Neither loads anything in the window.
   - **On the Import page** these reads are marked *Flip Desk window*, with their page (*scrap.tf/buy/hats*) in place of a file name.
   - **Your sign-in** is kept in memory and gone when Flip Desk quits, unless you turn on *Stay signed in after Flip Desk quits*: then it is kept on this computer in the window's own browser storage until **Log out & clear**, which clears the window's cookies, site storage and cache. Flip Desk never reads either. A change to that switch applies when you close the window and open it again (the toolbar shows *Reopen to apply* meanwhile).
   - **Flip Desk's own scrap.tf links** (the Live market's scrap.tf button and bank link, *Open on scrap.tf* in the item panel and the row menu, and the banks cards) still open in your browser, or in this window once you turn on *Open Flip Desk's scrap.tf links in this window*. The Bank stock page's **Open** follows that switch too. Every other link, the scrap.tf/items card's browser button included, always opens in your browser, as its button says.
   - **What the app still never does:** load, reload or poll scrap.tf on its own, call its `/ajax` pages or its socket, click, type, scroll or change anything in the page, buy, queue or trade, read or reuse your cookies or sign-in, change its user agent, or get past a Cloudflare check for you. Every page load is your click or key press, and a read sends nothing over the network.
4. **See what's new on each bank.** Every save of a bank page is kept as a snapshot of what that page had at that moment (for up to 90 days, except each page's newest save and the one it is compared with; step 5 says which saves stay). Save a page again later and the app shows what changed since your previous session, with every item priced against live backpack.tf buyers. Saves of a page less than 30 minutes apart (a run of window reads, say) count as one session, and *What's new*, the **New** badges and the *New* chip compare your newest save with your last save from before that run; for saves made hours or days apart, that is simply your previous save.
   - **On each card** of the scrap.tf banks page: *Since your save 3 h ago: **5 new** (2 flips) · 3 gone · 2 cheaper · 1 pricier*. After a page's first save the card says *First save: save it again later to see what changed*.
   - **View stock** on a card opens that page's stock: every item of your newest save (of each page, when you save scrap.tf/items or the unusuals in several pages) with scrap.tf's price, its stock (*5 → 3* when it moved), who buys it on backpack.tf and for how much (bot or human, online or not), **Pay up to**, a verdict (*Flip +X (m%)*, *Over by Y* or *No buyers*) and confidence. A **New** badge marks items new since your previous save, *↓ was X* or *↑ was X* a price change, and *extras* a painted or spelled copy (its Pay up to is for a clean copy).
   - **Chips** with counts: *All* (in stock), *New*, *Flips*, *Price changes* and *Gone* (items no longer on the page, with their last price and when you last saw them). Search with `/`, sort by profit, margin, price, name or Pay up to, and **Export CSV**. Each page remembers its own chip, search and order. Click a row (or `Enter`) for the item panel, right-click it (or `Shift+F10`) for the row menu; `j`/`k` move. **Open in browser** hands the page to your browser, ready for the next `Ctrl+S` (with the window on, **Open in Flip Desk window** opens it there). A page of the bank saved more than two days before its newest page is left out of the counts and chips, and the header says *2 older pages (last saved 3 d ago)*. **Record buy…** on a row books that exact copy (a painted copy under its painted SKU) at the price it was listed for, noted *from your save of scrap.tf/buy/hats*.
   - **Elsewhere:** Live market rows new on a page you saved carry a **New** badge, and *New on scrap.tf* under *Source* keeps only those. A bank last saved more than a day ago marks nothing **New**. The item panel says *On scrap.tf/buy/hats in your save 12 min ago: 3 in stock, new since your previous save* (or *↓ cheaper than before (was X)*, *↑ pricier*, or *gone*), with **View stock**.
   - **Notifications:** when a save brings new items that are flips, *New on scrap.tf (Hats): (item name)* with the price, what it sells for, to whom, and your profit. At most three per save, then one summary; each item once per page every 30 minutes; nothing for a page's first save, or for a page imported again. They use your notification switches and thresholds (*Imported pages* ticked under *Notify for*, the minimum confidence and profit), and a suspect margin is never notified. Such an item gets this notification instead of a second *Profit:* one. A save older than your *Price is stale after* time (a page the folder watch catches up on at start, say) gets one summary instead, *3 new flips in your save of scrap.tf/buy/hats from 2 d ago*, and a save 15 minutes old or more adds *in your save 40 min ago* to each notification. Turn them off in Settings → Notifications (*New flips on scrap.tf pages you save*).
   - **Flip Desk never loads scrap.tf on its own.** Every change is between two pages you saved or read yourself; what happened between them is unknown.
5. **Track scrap.tf prices over time.** Each save of a bank page is one point in that page's price history. Save your banks regularly (whenever you start a session, say) and the app shows how prices and stock moved from save to save, how long each item has been on sale, and every change in one feed.
   - **Item panel → scrap.tf history:** a step chart of scrap.tf's price in each of your saves of the item's page, with a gap where a save did not have it on sale (hover for that save's price); *Listed since 2 d 4 h (since your save on Oct 14 09:12)*; its price and stock now; chips for how the price moved over the last hour, day and week and since it was listed (*↓ 0.11 ref (−8 %)*), and its latest price changes, with stock moves listed apart. A chip shows *—* when no older save covers that span: save the page again later.
   - **Bank stock page:** a **Listed** column (how long the item has been on sale in your saves of the page, from the first to the newest save that had it, bold from a day; *last seen 3 d ago* when that newest save is over two days old) and **Since listed** (*↓ 8 %* when it got cheaper since then), both sortable, and the chips **Listed > 24 h** and **Dropped since listed**.
   - **Live log → scrap.tf changes** (next to *Opportunity events*): every change between two saves of a page, newest first. *New*, *Gone*, *Cheaper*, *Pricier*, *Restocked* (back on sale, and an earlier save you kept had it) and *Stock* (the count moved, the price did not), each with the item, *1.33 → 1.22 ref (−8 %)* and the stock, next to what it sells for on backpack.tf right now and its Pay up to. A **Flip** pill marks a change whose new price is at or under Pay up to, on the newest change of a copy still on sale; an older one gets a muted *was a flip*. Filter by bank and kind (remembered; *Stock* moves are hidden until you tick them), **Load older changes**, **Export CSV**; click a row for the item panel, right-click it for the row menu. The tab updates by itself after each save that changed something.
   - **Live market:** *Listed on scrap.tf > 24 h* under *Source* keeps the items your saves have had on sale for at least a day, measured between your saves (a page saved once long ago does not count as listed since then).
   - **Re-save reminders** (off by default): Settings → *Saved-page import* → *Remind me to save a bank again after* N minutes, for every bank you have saved or only the ones you tick. A bank you have not saved for that long gets a desktop notification, *Re-save scrap.tf/buy/hats* / *Last saved 1 h 05 m ago. Save it again (Ctrl+S, 'Webpage, Complete') to refresh prices and see what changed*, then at most one every N minutes until you save it. Clicking it opens that bank page in your browser, ready for `Ctrl+S`. With the scrap.tf window on and *Open Flip Desk's scrap.tf links in this window* ticked, its text says to open the page in the Flip Desk window instead. None comes while import or notifications are off or the network is paused, and never for a bank you have never saved. *Silent notifications* applies.
   - **What is kept:** every save from the last 2 hours (at most 300 per page), then one every 10 minutes for the rest of the day, then one an hour for a week, then one a day up to 90 days. A page's newest save, the one it is compared with and your last save before the current session always stay. The change feed keeps 90 days.
   - **Flip Desk never loads scrap.tf on its own.** It cannot refresh scrap.tf for you: the history is made of the pages you saved or read, a reminder only asks you to save one again, and nothing is known between two saves.
6. **Open the Shopping list, then browse scrap.tf yourself**, as you normally would. For every item the app tracks, the list shows **Pay up to**: the highest scrap.tf price that still clears your profit thresholds against live backpack.tf buy orders. Anything priced at or under it is a flip. Items are grouped by scrap.tf bank page; a group's link opens that page in your browser. You can also export the list as CSV. *Your price* says how old it is (*1.33 ref · 3 h ago*); one older than your *Price is stale after* time (2 hours by default) reads *stale* and is not counted as at or under Pay up to, since scrap.tf may no longer charge it.
7. **Live check while you browse.** Copy an item on scrap.tf and see its flip at once, without leaving the page.
   - **What to copy:** an item's name, or better, its whole row on scrap.tf/items: select from the name to the *Item Limits* column and press `Ctrl+C`. A row also tells the app scrap.tf's price, what scrap.tf pays and its stock. A name and price on two lines, `Team Captain, 1.33 ref` (the *Paste a list* format), a SKU, or a backpack.tf, marketplace.tf or PriceDB item link (alone or followed by a price) work too. Other links are not checked, and a scrap.tf link does not work: Flip Desk does not open scrap.tf links you copy.
   - **Press the check hotkey,** `Ctrl+Alt+C` by default. The app reads the clipboard once, on this computer, and a small window opens in the bottom-right corner. It shows the item, scrap.tf's price and where it came from (*copied*, *saved list 3 min ago* or *your price*) with the stock, what the item sells for on backpack.tf and to whom, and a verdict: *Flip +X (margin)*, *Over by Y*, *No buyers*, or *No scrap.tf price*. It always shows **Pay up to**, and leads with it when there is no price to compare. The price is the copied one first, else your saved scrap.tf list's, else your own newest price. A row copied as *Sold out* has no price. Holding the keys down checks once.
   - **Act on it:** **Save price** (`Enter`) saves the price as yours (note *live check*), with no *Profit:* notification for it right after. **Bought it** (`B`) records the buy in your journal, with **Undo**. **Details** (`D`) opens the item panel. **Quick entry…** opens quick entry with the item and the price filled in. The window hides itself after 10 seconds unless you point at it, and `Esc` hides it at once.
   - **Clipboard check** (off by default): Settings → Live check → *Watch the clipboard*, or *Clipboard check* in the tray menu. *Flip Desk reads text you copy and checks it if it is a TF2 item. Nothing is stored or sent.* While it is on, each new item you copy opens the same window without taking the focus from your browser, at most one every 1.5 seconds. While the window is switched off (Settings → Live check), a flip shows a desktop notification instead, at most once a minute per item and never for a saved-list, typed or imported price older than your *Price is stale after* time; with it on, the window is the one alert. Text that is not an item is ignored silently. It skips anything that looks like a password, key, token or card number, and any long link that is not a backpack.tf, marketplace.tf or PriceDB item link (other links can carry a login token), never checks what was already on the clipboard when you turned it on, and pauses while the screen is locked, the computer sleeps or the network is paused. Settings → Live check also has switches for the notification and for the window (the hotkey always shows it), and a **Test** button.
   - **Recent checks** on the Live market lists your last 30 checks; click one to open the item. Its box takes a pasted name or row if you would rather not use the hotkey.
   - **Flip Desk still never loads scrap.tf on its own or reads your browser.** It reads plain text you copied, only when you press the hotkey or while the clipboard check is on. The text is checked on this computer against the buy orders the app already stores and your saved list. It is never stored, logged or sent anywhere, and nothing new goes over the network.
8. **Or start from the Live market**, the second page. It lists every item that has a backpack.tf buyer in the live feed, plus every item you have priced. ## Where your data lives

Everything stays on your PC under `%APPDATA%\TF2 Flip Desk\`:

| Path | Contents |
|---|---|
| `data\flipdesk.sqlite` | order book, prices, opportunities, events, journal, your saved scrap.tf price list (rows older than 30 days are removed), snapshots of the scrap.tf pages you saved or read (every one of the last 2 hours, at most 300 per page, then thinned to one per 10 minutes for the rest of the day, one an hour up to a week and one a day after that, for up to 90 days, except each page's newest save, the one it is compared with and your last save before the current session, which stay until newer saves replace them) and the changes between them (90 days) |
| `logs\opportunities-YYYY-MM-DD.jsonl` | one JSON line per opportunity event. Kept as long as the events (90 days), 512 MB total cap. |
| `logs\service.log`, `logs\main.log` | diagnostics, with secrets redacted |
| `settings.json`, `secrets.json` | settings; DPAPI-encrypted key and token |
| `scraptf-window-bounds.json` | the scrap.tf window's size, place and whether it was maximised (0.7.1), so it reopens where you left it |
| `Partitions\scraptf\` | the scrap.tf window's cookies, site storage and cache, written by Chromium itself only when you chose *Stay signed in after Flip Desk quits*; cleared by **Log out & clear**. Flip Desk never reads it. |

The live feed uses roughly 13 GB/day of *decompressed* data, and much less on the wire because it is compressed. You can pause it or cap it in Settings. Turning the feed off only closes its connection: with an access token saved and *backpack.tf API* on, the items you price or hold still refresh in the background (one a minute at most, each at most every 30 minutes). Turn off *backpack.tf API* under Data sources, or pause all network, to stop every backpack.tf request.

- `npm test` runs about 6,100 vitest tests, including the compliance tests: network policy, static scans for forbidden calls and for scrap.tf pages opened from anything but the fixed list, the saved-page readers (pure, and nothing named inside a saved `.html` or `.mhtml` file is ever loaded), the clipboard rules (plain text only, read in main only, never logged), notification links (only a bank page's fixed address, checked again when clicked), the scrap.tf window (only one module may show scrap.tf, every page load comes from a user action and never a timer or an event, the one pinned read script, no preload, no user agent, header or cookie calls anywhere), the window test (only its harness may drive the window or answer its requests, and only main's diagnostics-gated branch loads it), and secret redaction. The tests that measure timings run last, as their own group.
- `npm run dev:renderer` serves the dashboard in a browser with mock data, at http://127.0.0.1:5199.
- `npm run dist` builds the NSIS installer into `release/`.
- **Smoke test** against the real app and live feeds (development builds):

  ```bash
  npx electron . --smoke-test=test/.tmp/smoke.json --user-data-dir=test/.tmp/ud --smoke-wait=45
  ```

- **Window test** of the scrap.tf window (development builds). It runs the real window, toolbar, page view and import against local copies of the test pages, and never contacts scrap.tf or any other site from the window:

  ```bash
  npm run build
  npx electron . --smoke-window=test/.tmp/window.json --user-data-dir=test/.tmp/ud-window
  ```

  - **What it proves.** Every request from the window is answered by a local router, and anything that is not http(s) is cancelled. During the run Chromium resolves no host name and uses no proxy, and nothing is handed to your browser. The report lists every request.
  - **Reads.** Three bank pages are read on load: /buy/hats, /unusuals and (from 0.7.2) /buy/killstreaks. Each is imported as a window read that must match a file import of the same page: the same items on sale, no change event, the same card count and the same number of stored prices. The killstreaks read (step 2b) must also store every kit under its weapon, store no kit without one anywhere (prices or bank stock), and skip *Professional Kit*, which names no weapon, with *needs-target* in the parser report. /buy/hats and /unusuals are then loaded again, so the key steps find them in the window's history.
  - **Keys.** F5, Ctrl+R, Alt+Left, Alt+Right and Alt+Home in the page move the window, and a held key does nothing. If Electron's synthetic key presses never reach the window's key handler, those steps are reported as *not testable*, not as failures.
  - **Other pages.** Steam's sign-in stays in the window and is never read. A Cloudflare-style 403 shows its notice and is neither read nor imported, even at a bank page's address. A partial look at the hats page stores no stock snapshot and marks nothing as gone.
  - **Clean-up.** *Log out & clear* empties the window's storage, closing it leaves nothing open, and only the pinned read script ever ran in the page.
  - **Result.** The JSON report lists each step with its result. The exit code is 0 when no step failed.
  - **When it refuses.** It turns the window on in the profile it runs in, so it refuses to start (exit 1) in a packaged build without `FLIPDESK_DIAGNOSTICS=1`, next to `--smoke-test`, or without a `--user-data-dir` of its own. The app's normal profile is refused.
  - **Before you run it.** Close Flip Desk first, because only one copy runs per machine. Keep the window in front for the key steps. The background service still loads item data from PriceDB and backpack.tf as usual.

## Known limits

- **backpack.tf keyed endpoints** (snapshot, IGetPrices, IGetCurrencies, users/info) were built from documentation and tested against fixtures. No credentials were available while building, so check *Data health* after you add yours.
- **Logged-in scrap.tf page formats** for import come from public markup and the original userscripts. If a saved page imports badly, the import result lists every skipped card and the reason.
- **scrap.tf bank pages were checked against synthesized pages.** The test pages for Weapons, Stranges, Killstreaks, Skins and Items were built from scrap.tf's public markup and the original userscripts, not saved from the live site, so some forms (*War Paint: …* titles, *★Unusual* skins, a crate's series shown only in its tooltip, the page ids used when a file has no address) are unconfirmed. A card the app cannot read is skipped with its reason in the import result; nothing is guessed. A crate shown without its series takes the item schema's only series, and a crate with several series is skipped. From 0.7.1 every skin is keyed the way backpack.tf buyers key it, whatever quality class scrap.tf gives the card: a Strange skin without an effect as Strange (`15000;11;w2;pk14`), an unusual Strange skin as Decorated with its effect and *strange*. How scrap.tf marks them could not be checked on the live site; if a skin's flips look wrong, compare the SKU with backpack.tf.
- **A save of scrap.tf/items takes over a bank page's prices.** When the list and a bank page price the same plain item, the newer save's price is kept. If that is the list, the item's flip counts under *All items* on the banks page and the item panel says *Seen on scrap.tf/items*; the bank page's card still says when you last saved it.
- **Cards scrap.tf adds after the page loads are in your save only with *Webpage, Complete* or *Webpage, Single File*.** Those write the page as your browser shows it; *Webpage, HTML only* writes it as it first loaded, so it can miss some cards or all of them. A bank page saved with none is not counted (*This page was saved without its items*) and your older prices from it stay in use. A save with fewer than half the cards of your save of the same page from the last 6 hours (when that save had 8 or more) stores its prices but no stock snapshot (*partial-read*); read or save the page again once every card shows. A smaller shortfall, or one against an older save, is a save like any other, and on its stock page the missing cards read as gone until you save it again.
- **A bank page that stored nothing is not counted, whatever the reason.** The app tells a save without its cards by what it stored, so a page whose every card was skipped or was already priced by a newer save is passed over too: its card keeps the date of your previous save. While item data is still loading at start, no page is imported at all: the folder watch waits, and **Import saved page…** and the window say to try again in a moment.
- **scrap.tf/items stock comes from the tooltip.** The list shows each item's stock in a bar whose numbers live in a tooltip. Flip Desk reads them from the tooltip's attributes after the page's tooltips ran (*title*, *data-original-title*, *data-bs-original-title*, *aria-label*) or from the bar's own numbers. A row whose stock cannot be read (*no-stock-limit*) is not stored as a price, and that save stores no stock snapshot.
- **A card gone from a newer save loses its imported price.** Only prices imported from that bank's pages go; a price you typed, one from scrap.tf/items, and a card another page of the bank still lists (it moved) keep theirs. A save cut short or partial removes nothing.
- **A changed page layout is reported, not guessed.** When scrap.tf's markup no longer matches what Flip Desk reads, the import says *layout-changed* (item elements it did not recognise) or *no-price-column* (a list without a *Price to buy* column, whose prices are then not read). **Copy parser report** on the Import page gives a summary to report it with. A scrap.tf/items list that stored nothing (every row sold out) still counts.
- **A large Single File save is refused.** A Single File save holds every image of the page in the `.mhtml` file. One over 20 MB (the import's size limit) or with more than 2,000 parts (images, style sheets) imports nothing: *too-large* or *mhtml-too-many-parts* on the Import page, plus a notice on any dashboard page when the folder watch passes over a file for its size (**Import saved page…** says the same in its error). scrap.tf/items, with an image for every item, goes over; so can a very large bank. Save those as *Webpage, Complete*, which keeps the images in its `_files` folder, so the page stays small.
- **An `.mhtml` file cut short imports nothing.** When the file ends inside its web page (a copy cut off, say), the import says *mhtml-truncated … save the page again* and stores nothing, so the cards after the cut never read as gone from the bank's stock.
- **`.mhtml` was checked against synthesized files**, built from the test pages in the form Chromium browsers (Chrome, Edge) write: quoted-printable or base64, UTF-8. A web page part in another charset is read with it; a non-UTF-8 page stored as raw 8-bit text, which these browsers do not write, can lose its accented letters. The 20 MB limit applies to the page once decoded, too (each unreadable byte or non-English letter can take up to three bytes), so such a page can be refused as *too-large* though its file is smaller: *the page decodes to … MB* on the Import page, also when the folder watch picked it up.
- **A page the app does not recognise** (saved from an unknown scrap.tf address, or one scrap.tf renamed) still imports. The Import result says *Not recognised* and the page is filed by the categories of the items it holds.
- **PriceDB's live socket** was silent during testing. Prices still refresh through PriceDB's REST API on a schedule.
- **Live market and unusual effects.** An unusual effect whose only buyers are "any effect" orders appears in the Live market once you have priced it; the book has nothing per effect to list it by before that. Opportunities works the same way. Holdings does price such an effect, because it looks up each held item on its own.
- **Holdings know only what you record.** A trade you did not record, or recorded twice, makes the quantities and costs wrong; fix it in the Journal. Sales are matched to buys oldest first (FIFO).
- **Holdings value a clean copy.** Paint and spells add nothing to the buyer price; such rows are flagged *has extras*. Keys and metal you recorded as trades are listed without buyers.
- **Undo after a delete elsewhere.** If you delete a recorded trade on the Journal page and then press Undo on its confirmation, the confirmation still says it was removed. Nothing else changes.
- **Saved-page strip and pages imported with 0.2.** From 0.3 the app notes which bank page each saved page was when it imports it. A page imported with 0.2 is judged by the prices it still holds, so after a later import of scrap.tf's item list it can show as older, or *never saved*, until you save it again. It only ever errs towards saving again.
- **The scrap.tf price list is as fresh as your last save.** Prices and stock change on scrap.tf between saves, so the card, the item panel and the tooltips always say when you saved it. A list more than a day old is still shown (dimmed, *Over a day old*) but is never used as a place to sell; save scrap.tf/items again. Rows older than 30 days are removed.
- **A saved list keeps capping the key price.** scrap.tf's key prices from the list cap the automatic key value until you type newer ones or the row is 30 days old, like typed scrap.tf key prices. The cap can only lower the key value.
- **scrap.tf's room to buy.** *Full* means scrap.tf is at its limit as of your save. When it has room for fewer units than you hold, Holdings still values every unit at scrap.tf's price.
- **Painted and spelled copies.** scrap.tf/items lists plain copies only, so a painted item uses its plain copy's list row; the item panel and quick entry mark it *(plain copy)*.
- **Live market rows.** An item only scrap.tf trades, with no backpack.tf buyer, none in stock on scrap.tf and no price of yours, has no Live market row; its list row still shows in the item panel and Holdings.
- **Use as my price** saves a typed price like any other, so that item joins the short list the app keeps fresh with backpack.tf snapshots, inside the same request budget. Nothing is sent to scrap.tf.
- **Live check is as current as what you copied.** A copied row's price and stock are as of the copy, a saved list's as of the save, and buy orders as of the live feed. If scrap.tf lays out a row differently and the copy is not recognised, copy the item's name alone.
- **Misspelt names.** A name that is not exact is used only when it matches exactly one item, and the window then says *Closest match only*. Otherwise the check says no item was recognised; copy the exact name or the row.
- **Painted items in Live check.** scrap.tf/items prices plain copies, so a painted item's check never uses the list's price; it uses your own price for that copy, if any. The other way round, when your only price for an item is for a copy with extras (paint, spells, parts or a tag), checking the plain item shows that price with the note *Your price is for a copy with extras*, sends no flip notification, and leaves **Bought it** off.
- **Default check hotkey on AltGr keyboards.** `Ctrl+Alt+C` is the same keys as `AltGr+C`, which types a letter on some layouts (Polish *ć*, for example). If you type that letter, choose another shortcut in Settings → Live check. The quick-entry default `Ctrl+Alt+F` works the same way.
- **The clipboard check sees the app's own copies.** With it on, the menus' copy actions (*Copy name*, *Copy SKU* and the like) also open a check window for that item. *Open on scrap.tf (copies name)* and the Live market's scrap.tf button do not: their copy of the name is skipped once, if it reaches the clipboard check within a few seconds. In the rare case it arrives later (a very slow clipboard), it opens a check window for that item too.
- **A price copied on its own is checked as the item you opened last.** For 10 minutes after you open an item on scrap.tf from the app, or until you save its price or record the buy, a bare price is checked as that item, and the window says *Price copied, matched to the item you opened*. If you look at another item there meanwhile, copy its name with the price, or its whole row. Only a price counts: a number without a unit is read as ref when it is short (*5*, *1.33*, *63.11*), so a year, a code, a phone number or a SteamID is never taken for one. The clipboard check, which sees what you copy in any app, needs a unit (*5 ref*, *2 keys*) or a decimal (*1.33*); a whole number alone is checked only when you press the check hotkey.
- **Password managers.** The clipboard check cannot see a password manager's "do not watch" mark, because the app reads plain text only. API keys, tokens, card numbers, links other than item links and any 20-plus-character run without spaces that mixes letters, digits or symbols are skipped. A shorter password, or a passphrase with spaces, copied while it is on is checked like any other text: in memory, on this computer, and never stored, logged or shown. Turn it off from the tray first if you prefer.
- **Recent checks** live in memory only and are gone when the app closes.
- **What's new is only as complete as your saves.** It compares your newest save of a page with your last save from before the current session (saves less than 30 minutes apart are one session; while all of a page's saves are one session, with the save just before the newest), each a snapshot of that moment. An item that came and went between them is never seen, and stock between saves is unknown. Only items on sale count: a sold-out item that comes back counts as new, one that sells out as gone. A save that missed some cards (*HTML only* keeps the page as it first loaded) shows them as gone; save it again as *Webpage, Complete*. A save with no card at all is not compared: the next save is compared with your last one that had cards. A page imported twice (the folder watch and the Import page's picker, say) still compares with the save before it.
- **Changes are compared per page you saved.** scrap.tf/items/2 is only compared with your earlier save of scrap.tf/items/2, never with scrap.tf/items, and the same goes for each page of the unusuals; so the first save of each page shows no changes. The stock page lists your newest save of every page together, and its header says how many pages and how old the oldest one is. An item that moved from one page of the list to another between your saves can read as new on the page it moved to.
- **Pages saved before 0.6** kept no snapshot. Their cards say *First save* and their stock pages *No save of … yet* until you save them again; what changed shows once you have saved a page twice with 0.6.
- **New badge and item panel.** The Live market's **New** badge counts any copy of the item (painted or spelled too) new on any page you saved. The item panel shows your newest save that lists that exact copy, which can be another page (often scrap.tf/items) where it is unchanged; the badge's tooltip says so.
- **Stock of an item on several cards.** On a bank's stock page an item's stock adds up every card of it on sale (a "3x" stack and a reserved copy, say), while its price is the cheapest card's. So it can be higher than the stock the Live market shows next to that price, which is that one card's.
- **New-flip notifications at start-up.** Pages the folder watch picks up when the app starts are notified once the Live market has built, a few seconds later. If the opportunity engine told you of such an item first, its *Profit:* notification is the only one you get for it.
- **scrap.tf history has gaps between saves and covers only pages you saved.** Each point is one save; what happened between two saves (a price that moved and moved back, an item that came and went) is unknown, and an item on a page you never saved has no history. Older history is thinner: after 2 hours one save per 10 minutes is kept, after a day one an hour, after a week one a day, and nothing past 90 days but a page's newest save and the one it is compared with. More than 300 saves of one page within 2 hours (only by pressing **Read page now** very often) drop the oldest of them. *Listed since* and *Since listed* count only the saves still kept, so once the first save of a run is thinned an item reads as listed a little less long. The change feed keeps every change for 90 days, including those between saves that were thinned since.
- **Restocked needs an earlier save.** An item back on sale reads *Restocked* when a save you still keep of that bank listed it before, else *New*. An item that moved from one page of scrap.tf/items (or of the unusuals) to another is not *Gone* from the bank, but can read *Restocked* on the page it moved to.
- **Painted copies from the change feed.** A change of a painted or spelled copy opens the item panel of the item itself, whose *scrap.tf history* shows the clean copy. The change and its price are still the painted copy's.
- **Re-save reminders run only while the app runs.** They come up to a minute late, and the app remembers which banks it reminded you of only until it closes, so after a restart a bank can be reminded of once more. A reminder only asks you to save the page; the app cannot refresh scrap.tf.
- **The first look at the history after a start** reads every save kept. With hundreds of saves of every bank page it can take a second or two, once.
- **Cloudflare may challenge the scrap.tf window.** scrap.tf sits behind Cloudflare, which can show its check to an embedded browser more often than to your usual one. Solve it yourself in the window; Flip Desk never solves or skips it, and never retries a page on its own. The check page is not read when it loads (the toolbar says a check or error page is on screen), and the page you land on after it is read when it loads; if it is not, press **Read page now**. A rate-limit page (HTTP 429) says to wait a minute before reloading.
- **The scrap.tf window was tested with stand-ins, not on the live site.** Its tests run against fakes of Electron's window and of scrap.tf's pages (the same synthetic pages as the import), so how scrap.tf, Steam's sign-in and Cloudflare behave inside it is unconfirmed. If a read imports badly, the Import page lists it like any save.
- **A window read is a snapshot, like a save.** It holds what was on screen at that moment: the load's two snapshots are one save (the one 4 seconds later, unless it got nothing), so cards scrap.tf adds within those seconds are neither *gone* nor *new*. Cards added later still are caught by **Read page now**, which is a save of its own, so a bank card's *What's new* can then compare it with the load's save a few seconds before. A read cut short before its second snapshot, or one that caught fewer than half the cards of a read of the page in the last 6 hours, keeps its prices but no stock snapshot, so the missing cards do not read as gone; a smaller shortfall still does until the next read.
- **Notifications while you read in the window.** Each read dates the prices on screen anew, so a flip still on the page after your repeat time (*Repeat for the same item…*) can notify again while you keep reading that page.
- **Popups in the scrap.tf window.** A scrap.tf link that opens a new window does nothing there; open the page in the window itself. A popup to another site the app links to opens in your browser, but only within 5 seconds of your click or key press in the page, one tab per click.
- **Stay signed in applies when the window is reopened.** A change while it is open waits until you close it and open it again (the toolbar shows *Reopen to apply*). Turning it off moves the window to an in-memory session then, but a sign-in kept on disk before stays there until **Log out & clear**, which clears both.
- **Keyboard and the scrap.tf window.** The toolbar's controls are all reachable from the keyboard, and from 0.7.1 its keys (`Alt+Left`, `Alt+Right`, `F5`, `Ctrl+R`, `Alt+Home`) and the mouse's back and forward buttons also work while the page has the focus. Flip Desk still never moves the focus into the scrap.tf page itself; click in the page to start using it with the keyboard.
